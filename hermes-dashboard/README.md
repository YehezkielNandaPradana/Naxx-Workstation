# Hermes Dashboard (Naxx WorkStation)

Web dashboard sentral untuk memantau status ekosistem Hermes Agent (Nazza & Delta), memonitor gateway, visualisasi session tool stream, dan cron task manager.

## 🚀 Menjalankan Project

```bash
# Jalankan dev server (port 3100)
npm run dev

# Build production bundle
npm run build

# Preview build production
npm run preview
```

## 🌐 Koneksi Gateway Lokal
- Hermes Gateway: `http://127.0.0.1:8642`
- 9Router Gateway: `http://127.0.0.1:20128`
- Dashboard UI: `http://localhost:3100`
